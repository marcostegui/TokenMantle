# TokenMantle

TokenMantle implements a decentralized, autonomous network for distributed identity verification and real-time data processing.

TokenMantle is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/TokenMantle.git`
2. `cd TokenMantle`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
